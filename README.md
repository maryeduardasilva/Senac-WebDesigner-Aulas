# EcoTrilhas - Projeto de Aprendizado

## Sobre o Projeto

Este é um projeto educacional desenvolvido para aprender e praticar **HTML**, **CSS** e **JavaScript**. 

O site apresenta uma empresa fictícia de turismo de aventura chamada **EcoTrilhas**, onde utilizamos conceitos fundamentais de desenvolvimento web.

## Objetivo

- Aprender estrutura HTML semântica
- Praticar estilos com CSS
- Implementar interatividade com JavaScript

## Páginas

- **index.html** - Página inicial com expedições
- **parceiros.html** - Página de parceiros
- **quemSomos.html** - Página sobre a empresa
- **contato.html** - Página de contato

## Estrutura

```
aula1/
├── index.html
├── parceiros.html
├── quemSomos.html
├── css/
│   └── style.css
├── img/
└── testes/
```

## Como Usar

1. Abra o arquivo `index.html` no seu navegador
2. Navegue pelos links do menu para explorar as diferentes páginas

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (em desenvolvimento)
